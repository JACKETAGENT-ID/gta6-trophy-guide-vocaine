Leonida Nights is a retro-sunset, fully offline checklist and guide for all 55 GTA 6 PlayStation 5 trophies, with an original 3–5 sentence guide, missable flags and named sources for every trophy. A seven-stage roadmap timeline leads the page, and your progress — checkboxes, per-grade counts and percentage — is saved locally, with JSON export/import and a spoiler shield that hides story trophies until you earn them.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080 in a browser. The guide works fully offline.
